# DJ Kaszanka

Business-card website for a fictional DJ — a front-end portfolio project.

Live: https://djkaszanka.netlify.app/

## Stack

- React 19 + Vite
- React Router
- Tailwind CSS 4
- Motion (animations)

## Scripts

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
npm run lint     # ESLint
```

Deployed on Netlify; `public/_redirects` makes client-side routes work on page refresh.
